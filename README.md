# Recursos del Máster · RRHH 📚

🌐 ** (https://melinarivera.github.io/Recursos_de_estudio_MasterRRHH/)**

Página web con resúmenes en PDF y tests interactivos de todos los módulos del
Máster en Dirección y Gestión de RRHH — Universidad Europea.

## ¿Qué hay aquí?

| Módulo | Contenido | Preguntas |
|--------|-----------|-----------|
| M1 · RR.HH. y Empresa | Canvas, Porter, CMI, EX, estadística | 40 |
| M2 · Gestión Estratégica | Cambio, conocimiento, diversidad, Agile | 40 |
| M3 · Marco Jurídico | Teletrabajo, contratos, RGPD, PRL, huelga | 40 |
| M4 · Gestión de Personas | Selección, formación, evaluación, despido | 35 |

## Funcionalidades

- ✅ Tests interactivos tipo examen con 4 opciones por pregunta
- ✅ Explicación justificada tras cada respuesta
- ✅ Barra de progreso y marcador en tiempo real
- ✅ Calificación automática al terminar (Sobresaliente / Notable / Aprobado / Suspenso)
- ✅ PDFs descargables por módulo
- ✅ Responsive (funciona en celular)

## Tecnología

HTML + CSS + JavaScript vanilla. Sin frameworks, sin dependencias,
sin instalación. Abre `index.html` en el navegador y listo.
